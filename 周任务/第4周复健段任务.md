## Day 4（1.5h）跳转表：函数指针数组

**学什么**
- **跳转表**：`void (*table[4])(void) = {led_on, led_off, beep, reset};` 是一排存函数门牌的格子，用命令号当下标直接调。
  它替掉一长串 `switch-case`：加一个命令 = 表里加一格，`dispatch` 一个字都不用改。
  【看】`周任务/第4周任务.md` 的 Day 4 那节 + 自己 `week4/day3_01.c` 里 `int (*op)(int,int)` 的注释
- **越界检查**：`if (cmd < 0 || cmd >= 4) return;` 是「非法命令不得跳飞」的最后一道闸。
  表下标是外部输入时，**不查就等于把 PC 交给调用方**。
  【看】任务书本节

**动手**（都在 → `week4/cmd_table.c`，你昨天已经写好了四个函数和空 `main`，从 3 接着做）
1. 建表前先在注释里把 `void (*table[4])(void)` 从里往外读一遍：先 `table[4]`（数组）→ `(*...)`（装函数指针）→ `(void)` 参数空 / 前面 `void` 返回值空。
2. 写 `void dispatch(int cmd)`：越界打印 `bad cmd` 并 `return`，合法就 `table[cmd]();`（函数后面**必须带括号**）。
3. `main` 里 `for (int i = -1; i <= 4; i++) dispatch(i);`，看 `-1` 和 `4` 被挡、`0~3` 正常执行。
4. 改成 `void (*const table[4])(void)`，再编译一次；在注释写一句：为什么固件里表通常是 `const`（放 Flash，不占 RAM）。
5. 加分：把 `if (cmd < 0 || cmd >= 4)` 换成 `if ((unsigned)cmd >= 4u)`，验证行为不变，注释写清为什么一行就够（负数转无符号会变成很大）。

## Day 5 上（1.5h）跳转表升级版：带参数 + 命令名表

**学什么**
- **统一签名**：`void (*)(int arg)` —— 表里每一格必须是同一种门牌，才能放进同一个数组。
  想给不同命令传不同参数，就让参数「最宽的那个」统一接收，命令自己解释。
  【看】任务书本节
- **两张表下标对齐**：`const char *cmd_name[4]` 和 `table[4]` 一格对一格，`dispatch` 先打名字再执行。
  这是「命令表」的全部秘密，也是串口命令解析器（第 8 周）的雏形。
  【看】任务书本节

**动手**（继续 → `week4/cmd_table.c`，先备份成 `cmd_table_v1.c` 保存无参版，方便对比）
1. 四个函数改成 `void led_on(int arg)` 形式，打印里带上 `arg`。
2. 表类型改成 `void (*const table[4])(int)`。
3. 加 `const char *cmd_name[4] = {"led_on","led_off","beep","reset"};`
4. `dispatch(int cmd, int arg)` 执行前打 `[cmd] led_on(arg=3)` 这种格式；越界仍然挡住。
5. `main` 里把 `-1 / 4 / 0~3` 全覆盖跑一遍，输出贴进注释。

## Day 5 下（1.5h）回调注册表：静态数组，不用 malloc

**学什么**
- **回调注册表**：`static event_cb s_cbs[4] = {0};` 是一排「空槽」，别人把自己的函数门牌登记进来，事件来了挨个调。
  本质还是跳转表，区别是**运行时谁想挂谁挂**，而跳转表是编译时写死的。
  【看】任务书本节
- **返回值约定**：`int register_cb(...)` 成功返 0 / 满返 -1，**返回值代表什么必须先写注释再写代码**。
  调用方要靠它判断「挂失败」，否则中断里你以为注册上了，实际一个都没响应。
  【看】任务书本节

**动手**（新文件 → `week4/callback.c`）
1. `typedef void (*event_cb)(int event);`
2. `static event_cb s_cbs[4] = {0};`（注释写清 `{0}` 是什么意思：四个空槽，NULL）
3. `int register_cb(event_cb cb)`：找第一个 `== NULL` 的槽放进去，返回下标；满了返回 -1。
4. `void fire(int event)`：遍历，非空槽就调用并打印「槽 i 被调用」。
   —— **空槽必须跳过，不许调 NULL**（这是崩溃第一名的错法）。
5. 注册 2 个 → `fire(1)` 看两个都响应；再注册满 4 个 → 第 5 次注册返回 -1；`fire` 一个没注册的槽 → 安静跳过。
6. 文件头注释答一句：「中断里来事件，为什么『表 + 注册』比 `switch` 更安全？」

**今日产出**：`week4/callback.c`（空位注册 / 满返回 -1 / 空槽跳过）
