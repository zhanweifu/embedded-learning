## Day 1（10/12 周一 · 1.5h）函数基础

**学什么**
- 函数三要素：返回类型、函数名、参数列表
- 函数**先声明后使用**（定义写在 `main` 后面时，前面要写原型）

## Day 2（10/13 周二 · 1.5h）参数传递 + 作用域

**学什么**
- **C 只有值传递**：函数拿到的是实参的副本，改副本不影响原来的变量
- 局部变量、全局变量、`static` 局部变量（只初始化一次，跨调用保留）
- 变量作用域：`{ }` 内有效；全局变量为什么在嵌入式里尽量少用

**动手**
1. `void swap(int a, int b)`：交换后回到 `main` 打印，**亲眼看到没换成功**（证明值传递）
2. 把 `swap` 改成用全局变量 `temp` 实现，交换成功（理解为什么这样不好，第 3 周学指针会根治）
3. `int counter(void)`：内部 `static int n = 0;` 每次调用返回 `++n`；连续调 5 次看输出
4. `int is_prime(int n)` 判断素数（把第 1 周逻辑封装成函数，处理 `n < 2`）
5. `int gcd(int a, int b)` 辗转相除法求最大公约数（用 while 写进函数）

## Day 3（10/14 周三 · 1.5h）一维数组

**学什么**
- 定义与初始化：`int a[5] = {1,2,3,4,5};`、`int a[5] = {0};`、未初始化是垃圾值
- 下标从 0 开始；**越界不会报错但会踩内存**（嵌入式大坑）
- 用 `for` 遍历；数组长度用 `sizeof(a)/sizeof(a[0])`
- 数组作为函数参数：`void f(int a[], int len)`，**必须另传长度**

**动手**
1. 数组 `{3,1,4,1,5,9,2,6}`：求总和、平均值、最大值、最小值
2. 数组逆序输出（原地交换，头尾对调）
3. 线性查找：输入一个数，输出它在数组中的下标，找不到输出 -1
4. 冒泡排序：把数组从小到大排好再打印（手写两层循环，别调库）
5. `int count_even(int a[], int len)`：统计偶数个数（用 `& 1`）

## Day 5（10/16 周五 · 1.5h）环形缓冲区 Ring Buffer · 原理 + 骨架

**学什么**
- 为什么需要：串口/ADC 数据来得比处理快，用数组硬存会满 → 环形缓冲让读和写各跑各的，不丢数据
- 三个要素：**缓冲数组 + 写指针（head）+ 读指针（tail）**，到尾折回 0
- 空/满判定：常用"**牺牲一个单元**"法——`head == tail` 为空，`(head+1)%size == tail` 为满
- `% size` 取模实现折回（后面可用 `& (size-1)` 加速，要求 size 是 2 的幂）

**动手**
1. 定义结构体：`typedef struct { unsigned char buf[8]; int head, tail; int size; } ringbuf_t;`
2. `void rb_init(ringbuf_t *rb)`：head = tail = 0，size 设为 8
3. `int rb_is_empty(ringbuf_t *rb)` 和 `int rb_is_full(ringbuf_t *rb)`（用上面的判定）
4. `int rb_put(ringbuf_t *rb, unsigned char data)`：满则返回 0，否则写入 `buf[head]` 并让 head 折回
5. `int rb_get(ringbuf_t *rb, unsigned char *out)`：空则返回 0，否则取出 `buf[tail]` 并让 tail 折回
