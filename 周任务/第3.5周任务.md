## Day 2（10/27 周二 · 1.5h）strlib 骨架：`my_strlen` + `my_strcpy`

**先建三个文件**（这一天只填两个函数，剩下两个明天填）

### ① 新建 `week3/strlib.h`
```c
#ifndef STRLIB_H
#define STRLIB_H

#include <stddef.h>   /* size_t 在这里 */

/* 返回字符串长度（不含 '\0'）。传 NULL 返回 0。 */
size_t my_strlen(const char *s);

/* 把 src 连 '\0' 一起拷到 dst，返回 dst 原地址。dst 或 src 为 NULL 返回 NULL。 */
char *my_strcpy(char *dst, const char *src);

/* 比较两串：a<b 返回负数，相等返回 0，a>b 返回正数。有 NULL 时按 0 处理比。 */
int my_strcmp(const char *a, const char *b);

/* 把 src 接到 dst 末尾（覆盖 dst 原本的 '\0'），返回 dst 原地址。NULL 返回 NULL。 */
char *my_strcat(char *dst, const char *src);

/* 找 c 第一次出现的位置，返回该处指针；找不到返回 NULL。c=='\0' 返回指向结尾字符的指针。 */
char *my_strchr(const char *s, char c);

#endif
```

> `#ifndef / #define / #endif` 是**防重复包含**的护栏，先照抄，第 6 周讲头文件时再拆开讲。

### ② 新建 `week3/strlib.c`：只实现 `my_strlen` 和 `my_strcpy`

**骨架给你，函数体你自己写**：
```c
#include "strlib.h"

size_t my_strlen(const char *s) {
    if (!s) return 0;
    /* 你的代码：指针版，走到 '\0' 为止，返回走了几格 */
}

char *my_strcpy(char *dst, const char *src) {
    if (!dst || !src) return NULL;
    char *ret = dst;              /* 先记住原地址，最后还它 */
    /* 你的代码：把 src 一个字符一个字符搬到 dst，别忘了 '\0' 也要搬 */
    return ret;
}
```

**要求**：`my_strlen` 用指针版（`while (*s) s++;` 或 `while (*s++)`），不许用 `sizeof`，不许再写「用 strlen 实现 strlen」。

### ③ 新建 `week3/test_strlib.c`
至少测这 5 组：
- 正常串 `"hello"` → 长度 5，拷贝后 `strcmp` 相等
- 空串 `""` → 长度 0，拷贝后还是空串
- 单字符 `"a"` → 长度 1
- 中文串 `"嵌入式"` → 长度 9（UTF-8 一个汉字 3 字节，**这是重点**：`strlen` 数的是字节不是字）
- 传 `NULL` → 不崩，返回值符合注释

**上面这几行立刻验证**：`my_strcpy` 拷完要检查 `dst[5] == '\0'`（第 2 周踩过「'\0' 没抄过去」的坑）。

## Day 3（10/28 周三 · 1.5h）`my_strcmp` + `my_strcat`

**①（追加到 `week3/strlib.c`）** `my_strcmp`
- 一个循环：两串同步走，相同就一起前进，遇到不同或遇到 `'\0'` 就停
- 停下来后返回 `*a - *b`（正/负/0 天然满足「a<b 返回负」）
- **别做**：不要先算长度再比；不要返回 `*a > *b`（那是 1/0，丢了「谁大多少」）
- **别做**：不要比 `a > b`（那是**指针门牌号**比大小，Day4 你撞过，会段错误）

**②（追加到 `week3/strlib.c`）** `my_strcat`
- 两步：先把 `dst` 的笔走到它自己的 `'\0'` 上；再从那里照抄 `src`（连 `'\0'`）
- 返回 `dst` 原地址（先存 `ret`）

**③（追加到 `week3/test_strlib.c`）** 测试
- `"abc"` vs `"abd"` → 负数（打印出来看是不是 `-1`）
- `"abc"` vs `"abc"` → 0
- `"ab"` vs `"abc"` → 负数
- `"abc"` vs `"ab"` → 正数（**四种都要打印**，别只测一个方向）
- `strcat`：`"foo"` + `"bar"` → `"foobar"`；再链式叠一次 `+ "-end"` → `"foobar-end"`
- `strcat` 的空串边界：`"foo"` + `""` → 还是 `"foo"`

**今日产出**：4 个函数齐全，测试覆盖三种返回值方向

## Day 4（10/29 周四 · 1.5h）`my_strchr` + 回文重构

**①（追加到 `week3/strlib.c`）** `my_strchr`
```c
char *my_strchr(const char *s, char c) {
    if (!s) return NULL;
    /* 你的代码：
       走到 '\0' 为止，每格比一次 *s == c；
       注意 '\0' 那个位置也要比一次（C 标准：c=='\0' 返回指向结尾 '\0' 的指针）*/
}
```
> 这题是你在检测卷第 11 题翻车的地方：`const char *find = c;` 把**字符值**当地址。
> `s` 是门牌，`c` 是东西。要比较的是 `*s`（门后那间房里的东西）和 `c`（东西），**不能拿 c 当门牌**。

**② 新建 `week3/day4_06.c`**：回文函数重写（**先写测试，再写函数**）
```c
/* 先写 main：把下面 8 个案例全部列出来，打印期望值和实际值
   "a" / "" / "ab" / "aa" / "aba" / "abba" / "abcba" / "abca"
   期望：      1    1     0     1      1       1        1        0   */
int my_is_palindrome(const char *s) { ... }
```
- 条件必须是 `while (l < r)`（不是 `l != r`）
- 长度小于 2 才直接返回 1（`if (len < 2)`，不是 `<= 2`）
- **写完必须跑那 8 个案例**，尤其 `"abba"`（偶数长度）和 `"ab"`（长度 2）
