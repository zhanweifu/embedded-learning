## Day 2（10/06 周二 · 1.5h）位运算技巧专项 ⭐嵌入式核心

> 上周只是"初步接触"，今天要练到能用。**这周学的不是炫技，是以后摸寄存器的基本功。**

**学什么**
- 置位：`x |= (1 << n)`
- 清位：`x &= ~(1 << n)`
- 翻转：`x ^= (1 << n)`
- 取第 n 位：`(x >> n) & 1`
- 掩码提取：`(x >> n) & 0x0F`（取连续几位）
- 用一个 `unsigned char` 当"8 个开关"，一个字节存 8 个状态

**动手**
1. 输入一个整数，用循环 + 移位打印它的二进制（如 `5` → `00000101`）
2. 输入 `x` 和 `n`，分别输出：置位第 n 位 / 清位第 n 位 / 翻转第 n 位 / 查询第 n 位
3. 统计一个数的二进制里有多少个 `1`（写两种：循环移位 + `x &= x-1`）
4. 不用第三个变量，交换两个整数（用 `^` 异或）
5. 用 1 个 `unsigned char flags` 当 8 个 LED：写 `led_on/flags_off/led_toggle/led_query` 四个函数（用 `1<<n`），主程序里跑一遍

## Day 3（10/07 周三 · 1.5h）状态机（FSM）入门 ⭐嵌入式架构骨架

> 状态机听起来玄，其实就是「**当前处在哪个状态** + **来了什么事件** → **跳到哪个状态、做什么动作**」。用 `enum` + `switch` 就能写。

**学什么**
- 三个词：状态（State）、事件（Event）、转移（Transition）
- 用 `enum` 定义状态，`switch(state)` 处理
- 为什么比一堆 `if-else` 好维护

**动手**（都在 PC 上模拟，不需要硬件）
1. 电灯状态机：状态 = `关 / 开 / 闪烁`，事件 = 按下按键（用输入字符模拟），循环切换
2. 按键消抖状态机：定义 `空闲 / 疑似按下 / 确认按下 / 疑似松开`，给一串 `0/1` 输入，输出消抖后的稳定值
3. 红绿灯状态机：`红 / 绿 / 黄`，每次"走一步"换状态（用一个计数器控制）
4. 用状态机写"循环版计算器"的骨架：状态 = `等待输入 / 计算 / 退出`，输入 `q` 退出
5. 画出第 1 题的状态转移图（手画或画在笔记里，不要跳过这步）

**今日产出**：3 个状态机小程序 + 1 张状态转移图
