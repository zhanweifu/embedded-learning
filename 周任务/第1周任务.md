# 第 1 周任务（C 语言：基础语法）

> 主题：数据类型、运算符、分支、循环
> 本周产出：20 个小程序 + 一篇笔记
> 时间：工作日 1.5h/天，周末 6h/天

---

## Day 1（周一）环境 + 变量与数据类型

**学什么**
- 安装 VS Code + gcc，编译运行第一个程序
- `printf` 输出、`#include <stdio.h>`
- 数据类型：`int`、`float`、`double`、`char`、`long`
- 变量声明、赋值、`sizeof`

**动手（至少写 5 个程序）**
1. 输出 `Hello, Embedded!`
2. 定义 int/float/char 各一个变量并打印
3. 用 `sizeof` 打印每种类型的字节数
4. 计算圆的面积（输入半径）
5. 打印一个简单的个人信息表（姓名/年龄/成绩，用不同格式化输出）

**今日产出**：能编译运行、理解每种类型占几字节

## Day 2（周二）运算符 + 输入

**学什么**
- 算术运算符 `+ - * / %`（注意整数除法！）
- 关系运算符 `> < == !=`
- 逻辑运算符 `&& || !`
- 位运算符初步 `& | ^ ~ << >>`
- `scanf` 读取输入
- 类型转换（隐式/显式）

**动手**
1. 输入两个数，输出和、差、积、商、余数
2. 验证 `7 / 2` 和 `7.0 / 2` 的区别
3. 判断一个数是奇数还是偶数（用 `%` 和 `&` 两种写法）
4. 用位运算把某一位设为 1 / 清零
5. 输入秒数，换算成 时:分:秒

**今日产出**：理解整数除法陷阱、位运算基础
**卡点记录**：____________

## Day 3（周三）分支：if / switch

**学什么**
- `if`、`if-else`、`else if` 链
- 嵌套 if
- `switch-case` + `break`
- 三目运算符 `? :`

**动手**
1. 输入分数，输出等级（90+ A，80+ B，…）
2. 输入三个数，输出最大值（用 if 和三目各写一遍）
3. 判断闰年
4. 输入月份，用 switch 输出天数
5. 简易计算器：输入 `a 运算符 b`，输出结果
