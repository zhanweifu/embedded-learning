## Day 1（2026/09/30 周三）环境 + 变量与数据类型 ✅

**学什么**
- 安装 VS Code + gcc，编译运行第一个程序
- `printf` 输出、`#include <stdio.h>`
- 数据类型：`int`、`float`、`double`、`char`、`long`
- 变量声明、赋值、`sizeof`

**动手（至少写 5 个程序）**
1. 输出 `Hello, Embedded!`
2. 定义 int/float/char 各一个变量并打印
3. 用 `sizeof` 打印每种类型的字节数
4. 计算圆的面积（输入半径）
5. 打印一个简单的个人信息表（姓名/年龄/成绩，用不同格式化输出）

**卡点记录**：习惯性用 `getchar()` 暂停，已意识到；待改

## Day 2（2026/10/01 周四）运算符 + 输入 ✅

**学什么**
- 算术运算符 `+ - * / %`（注意整数除法！）
- 关系运算符 `> < == !=`
- 逻辑运算符 `&& || !`
- 位运算符初步 `& | ^ ~ << >>`
- `scanf` 读取输入
- 类型转换（隐式/显式）

**动手**
1. 输入两个数，输出和、差、积、商、余数
2. 验证 `7 / 2` 和 `7.0 / 2` 的区别
3. 判断一个数是奇数还是偶数（用 `%` 和 `&` 两种写法）
4. 用位运算把某一位设为 1 / 清零
5. 输入秒数，换算成 时:分:秒

**卡点记录**：位运算置位与清零都写出来了；部分文件漏 `return 0`；位运算仍不熟练，数字敏感性差

## Day 3（2026/10/02 周五）分支：if / switch ✅

**学什么**
- `if`、`if-else`、`else if` 链
- 嵌套 if
- `switch-case` + `break`
- 三目运算符 `? :`

**动手**
1. 输入分数，输出等级（90+ A，80+ B，…）
2. 输入三个数，输出最大值（用 if 和三目各写一遍）
3. 判断闰年
4. 输入月份，用 switch 输出天数
5. 简易计算器：输入 `a 运算符 b`，输出结果

**卡点记录**：闰年世纪年(1900)判错、day3_03 格式串笔误 `"%d是闰年,a"`；`switch(score/10)` 让 100 分落到 default；计算器未处理除零

## Day 4（2026/10/03 周六）for 循环 ✅

**学什么**

- 累加、累乘
