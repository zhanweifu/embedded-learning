## 二、改错题（3 题 × 12 分 = 36 分）

> 每题：① 指出错在哪（第几行、什么原因）；② 给出改法。**不用重写整个程序。**

**5.**（12 分）
```c
void swap(int a, int b) { int t = a; a = b; b = t; }

int main(void) {
    int x = 1, y = 2;
    swap(x, y);
    printf("%d %d\n", x, y);   /* 期望 2 1 */
    return 0;
}
```
输出是 `1 2`。错在哪？怎么改？

**6.**（12 分）
```c
void reverse(int *a, int n) {
    int *p = a, *q = a + n - 1;
    while (p < q) {
        int *k = q;      /* ← 这行 */
        *q = *p;
        *p = *k;
        p++; q--;
    }
}
```
输入 `{1,2,3,4}`，输出变成 `4 3 3 4`。指出那行的毛病，并给出一个字的改法。

**7.**（12 分）
```c
int is_palindrome(const char *s) {
    int len = 0;
    while (s[len]) len++;
    if (len <= 2) return 1;
    const char *l = s, *r = s + len - 1;
    while (l != r) {
        if (*l != *r) return 0;
        l++; r--;
    }
    return 1;
}
```
这段有**两处**判断条件写错，导致 `"abba"` 和 `"ab"` 都判错。哪两处？各自改成什么？
