## Day 1（10/19 周一 · 1.5h）地址与指针基础

**前 15 分钟：清第 2 周欠账**
- `day6_01.c`：`for` 里**不查** `rb_is_full`，直接 `rb_put`，靠返回值打印「成功/满了被拒」，期望 7 成功 2 被拒
- `day1_02.c`：`if (is_even(i)) printf("偶数");`（`==0` 删掉）
- `day2_04.c`：`if (n<2) return 0;` → 循环里撞到约数直接 `return 0` → 最后 `return 1;`；`main` 写 `if (is_prime(a)) yes else no`
- 顺带做第 2 周遗留的 6 题速答（我口头出，你打字答，10 分钟）

**学什么**
- 每个变量都在内存里有门牌号 → `&x` 取地址
- 指针就是一个存地址的变量：`int *p = &x;`
- `*p` 解引用：顺着地址去把那个格子里的东西取出来
- 指针也分类型：`int*` 和 `char*` 本身都占 8 字节（64 位），但 `*p` 一次取几字节、`p+1` 走多远，全看类型
- **野指针**：指针没指向任何有效内存就去 `*p`，等于拿别人家门牌号开门

**动手**
1. 连开 3 个 `int`，打印值和地址 `printf("%d %p\n", x, (void*)&x)`，看地址差几字节
2. `int x = 42; int *p = &x;` → `*p = 100;` → 打印 `x`，确认本体被改
3. 写 `void show(const char *tag, int *p)`：打印 tag、`p`、`*p`；`main` 里分别传 `&x` 和 `NULL`，`NULL` 那一路先判空再解引用
4. **故意的野指针实验**：`int *p; *p = 5;` 跑一次看它崩（或静默改坏别处）；然后改成 `int *p = NULL; if (p) *p = 5;` 看它安静 —— 这就是"防御"的由来
5. `printf("%d", p)` 把地址用 `%d` 强塞，看编译器 warning 长什么样（练习"读懂 warning"）
6. 把 `sizeof(int*)`、`sizeof(char*)`、`sizeof(int)` 都打出来

**今日产出**：5~6 个指针小实验，能徒口说清 `&` 和 `*` 是互逆动作

## Day 2（10/20 周二 · 1.5h）指针做参数：swap 根治

**学什么**
- C 只有值传递 → 但**地址也是一种值**。传 `&x` 进去，函数拿到的是"x 的门牌号"，自然能改到本体
- `void swap(int a, int b)` 永远是假的；`void swap(int *a, int *b)` 才是真的
- 指针做"输出参数"：一个函数返回一个值 + 通过指针吐出其余结果
- 二级指针 `int **pp` 先看一眼（第 4 周正式学）

**动手**
1. 重写 `swap(int *a, int *b)`，和第 2 周那个失败版放同一个文件里对比跑
2. `void minmax(const int a[], int len, int *min, int *max)`：一趟循环同时给出最小和最大
3. `int divmod(int a, int b, int *rem)`：返回商，余数从 `*rem` 吐出；`b==0` 时返回 0 并**不碰** `*rem`
4. `void bump(int *n)` 把计数器加一，`main` 里连调 5 次
5. 把第 2 周 `day2_02` 的「全局 temp 交换版」改成指针版，然后**删掉全局变量**，说明为什么更好

## Day 3（10/21 周三 · 1.5h）指针运算 + 指针与数组

**学什么**
- 核心恒等式：**`a[i]` 就是 `*(a + i)`**，`&a[i]` 就是 `a + i`
- `p + 1` 不是加 1 字节，是加"一个元素"——`int*` 走 4 字节，`char*` 走 1 字节
- 指针相减 = 相隔**几个元素**（不是字节数）
- 数组名是"常指针"，`a++` 编译不过；真指针 `p++` 可以
- 字符串字面量 `"hello"` 在只读区，写它就崩 —— **嵌入式里这是硬坑**

**动手**
1. 同一个 `int a[5]`，用三种写法各遍历一遍：`a[i]`、`*(a+i)`、`*p++`，输出必须一致
2. 打印 `&a[0] &a[1] &a[2]`，算出地址差，验证 = `sizeof(int)`
3. `int n = &a[4] - &a[1];` 打印 `n`，验证 = 3（不是 12）
4. **用指针重写第 2 周的 `day3_02` 数组逆序**（头尾双指针相向走，原地交换）——这是上周的欠账，今天用指针一次做干净
5. 危险实验：`char *s = "hello"; s[0] = 'H';` 跑一次（多半崩）；再改 `char s[] = "hello"; s[0] = 'H';` 成功 —— 亲眼看清"数组可改、字面量不可改"
6. 把 `a++` 写一遍，读一遍编译报错原文，抄进注释

**今日产出**：三种遍历 + 指针版逆序

**学什么**
- `char s[] = "abc"`（数组，可改）vs `char *s = "abc"`（指针，指向只读区）
- 手写字符串函数的**两种流派**：下标版和指针版，本周必须两种都会
- `while (*s)` 的妙处：`'\0'` 就是 0，条件天然为假
- `const char *` 的承诺：我不改你的串

**动手**
1. `size_t my_strlen(const char *s)`：指针版（`while(*s) s++;` 或 `while(*s++)`），下标版各写一遍
2. `char *my_strcpy(char *dst, const char *src)`：顺手返回 `dst` 原地址（为什么返回它就懂了 Day6 的链式调用）
3. `int my_strcmp(const char *a, const char *b)`：返回负/0/正，`main` 里测 `"abc" vs "abd"`、`"abc" vs "abc"`、`"ab" vs "abc"`
4. `char *my_strcat(char *dst, const char *src)`：先走到 dst 末尾再拷
5. 指针版回文判断：`const char *l = s, *r = s + my_strlen(s) - 1;` 相向走

## Day 5（10/23 周五 · 1.5h）指针改造 ringbuf + 位运算折回

**学什么**
- 你从 Day5（第 2 周）就在用指针了，只是没看清：`rb->head` 就是 `(*rb).head` 的糖
- `const ringbuf_t *rb`：只读访问，不消费
- **`% size` 改 `& (size-1)`**：为什么必须要求 size 是 2 的幂（第 2 周欠的挑战题①，今天还）
