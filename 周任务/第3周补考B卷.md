## 二、改错（3 题 × 12 分 = 36 分）

> 每题：① 指出错在哪（哪一行、什么原因）；② 给改法。**不用重写整个程序。**

**5.**（12 分）

```c
void minmax(int a, int b, int mx, int mn) {   /* 想让调用者拿到最大和最小 */
    if (a > b) { mx = a; mn = b; }
    else       { mx = b; mn = a; }
}

int main(void) {
    int x = 3, y = 9, big = 0, small = 0;
    minmax(x, y, big, small);
    printf("%d %d\n", big, small);   /* 期望 9 3，实际 0 0 */
    return 0;
}
```
改完的函数体仍要能正确分出大小。

**6.**（12 分）

```c
char *my_strcpy(char *dst, const char *src) {
    while (*dst++ = *src++)
        ;
    return dst;
}
```
这段有**两处**毛病（一处和返回值有关，一处和入口有关）：
- ① 哪两处？② 各改成什么？

**7.**（12 分）

```c
int my_strcmp(const char *a, const char *b) {
    while (*a == *b) { a++; b++; }
    return *a - *b;
}
```
- 比 `"abc"` 和 `"abc"` 时会发生什么？为什么？
- `while` 条件应该怎么改？（**只改这一行**）
